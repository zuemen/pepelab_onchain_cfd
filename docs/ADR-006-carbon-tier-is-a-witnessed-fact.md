# 碳分級的鏈上事實是見證的分級,不是從強度推導出來的結果

ADR-003 決定「碳強度直接決定資金成本」,並指向 `CarbonTiers`:一個純函式,把一個碳強度數字映射到 Low / Mid / High。`CarbonTiers.tierOf` 的單位是 **tCO2e / 每百萬美元營收**,而它自己的 NatSpec 明文警告:商品與加密貨幣沒有營收,把跨類別正規化的數字餵進去「不會 revert,只會靜默產生一個數字上一致、實質上錯誤的級距」,並要求這些資產的分級必須**直接指派**。

`docs/data/carbon-intensity.md` 的「Open questions for #95」段落也給了同一個建議(它的作法一):把分級(Low/Mid/High)當成鏈上事實逐資產儲存,`CarbonTiers` 消費分級而不是一個原始強度數字。

實作時兩者都沒有被採納。`PerpetualExchange` 讀見證登記所回傳的碳強度中位數,直接餵進 `tierOf`。見證登記所的紀錄結構裡沒有分級欄位,只有一個碳強度數字。結果是 11 檔資產裡有 5 檔(sBTC、sETH、sGOLD、sBOND、sICLN)是這種置放值 —— 部署腳本替它們反推一個「除下去會落在正確級距」的數字,而那個數字對使用者宣稱可以自己查證的承諾是假的。前端的碳資料結構同時帶了強度(可為 null)、一個獨立的分級欄位、和一個三值的基準欄位;合約那邊只有一個數字。兩邊各自自洽,合起來不是同一個模型。

決定是把既有文件推薦、但實作時走了另一條路的作法補做完:

1. **見證登記所的紀錄多帶兩個欄位。** 見證者直接見證**分級**(`CarbonTiers` 既有的四值列舉),並宣告這次見證用的是哪一種**基準**(營收 / 絕對 / 質性 —— 對齊前端既有的碳基準欄位)。碳強度欄位保留:營收基準的見證照樣寫,因為那是一個有單位、可稽核的量;非營收基準的見證不再需要為了落在正確級距而反推一個數字。
2. **新增一個依分級的中位數讀取。** 中位數取在分級列舉的序數上;過期見證不計入;沒有新鮮見證時回未評等且明確標示,比照既有讀取「不 revert,fail closed」的作法。永續交易所與金庫都改讀它。
3. **一條提交時的不變量。** 基準是營收的見證,如果宣告的分級與 `tierOf(強度)` 不一致就拒收。這是防止兩種表示法再度分岔的閘。非營收基準不套用 —— 對它們而言強度本來就沒有可比的意義。

`tierOf` **保留在函式庫裡**。營收基準的資產仍然要能從強度推分級;而且它正是上面那條提交不變量要用的東西。它只是不再是定價路徑上的一環 —— 沒有這份 ADR,未來的讀者會看到 `tierOf` 還在、卻沒有任何定價路徑呼叫它,而找不到原因。

## Considered options

**維持現狀:餵強度中位數進 `tierOf`。** 改動最小。否決:對 11 檔裡的 5 檔,鏈上的強度數字是一個為了落在某一級而反推出來的值,使用者查證不到;而 `CarbonTiers` 自己的 NatSpec 明文禁止這個用法。

**一個跨資產統一的正規化分數**(例如所有登記資產的百分位排名),在見證時計算。鏈上更優雅。否決:在公開場合更難防守 ——「為什麼這檔資產的分數是 62」比「這檔資產是 High,因為它的絕對年排放量超過 X」難回答得多。這也是 `carbon-intensity.md` 對同一個選項的評語。

**布林的 `revenueBasis` 欄位而非三值列舉。** 部署腳本現在就有一個這樣的布林。否決:它會把「按絕對排放量置放」和「按產業組成質性判定」壓成同一件事,而兩者的可稽核程度差很遠 —— 一個有第三方耗能統計可查,一個是「這是一檔綠色債券 ETF」的判斷。前端的身世卡本來就分開講三種,鏈上不該比畫面粗。

**把分級門檻或逐級參數改成可設定。** 更靈活。否決,理由同 ADR-003:一個可以被營運方調整的門檻就是一條可裁量的政策,而不可裁量是整套論述的立足點。它們維持 `internal constant`。

## Consequences

- **連鎖重部署。** 見證登記所是普通合約、沒有 proxy,改動紀錄結構只能重新部署。永續交易所持有的登記所位址是 immutable,所以它跟著;跟單追蹤與獎勵發放持有的交易所位址也是 immutable,所以它們也跟著。這與 #102 是同一條連鎖,是採納「補做完」而非將就現況的已知代價。金庫是 proxy,以原地升級接上(消耗既有的儲存保留槽)。實際的部署順序、腳本與重接線由部署那份 spec 負責。
- **金庫的買入費率由分級推導,並移除那個可設定的費率參數。** 「沒有任何路徑可以改變單一資產的買入費率」成為一個被測試釘住的缺席。登記所位址未設定時,買入費率退回最保守那一級的常數 —— fail closed,不是退回較便宜的預設值。贖回費率維持平費率(見 [ADR-005](./ADR-005-carbon-spot-prices-entry-not-holding.md))。
- **未評等或見證全部過期的資產一律落到最保守的一級。** 「沒有資料」不會被當成「沒有問題」。
- **這份 ADR 讓「不可比」變成鏈上可見的事實(基準欄位),而不是宣稱它解決了可比性。** 修正跨類別碳強度可比性這個更大的問題不在範圍內。
- 前端既有的碳資料結構不必為了配合鏈上而改形狀 —— 它本來就是這個模型(強度可為 null + 獨立分級 + 三值基準)。接上鏈上讀取時只是換資料來源。
- `docs/data/carbon-intensity.md` 的「Open questions for #95」就此解決(採納作法一),`CarbonTiers.sol` 的 NatSpec 一併更新。
